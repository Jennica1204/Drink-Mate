# Drink-Mate
DrinkMate adalah aplikasi pengingat minum air yang dikembangkan sebagai proyek kelompok dengan mengadaptasi aplikasi *Drink Water Reminder*. Aplikasi ini membantu pengguna memantau konsumsi air harian dan mencapai target hidrasi melalui fitur pencatatan jumlah air yang diminum.

Panduan Menjalankan Proyek

## Prasyarat
Pastikan perangkat telah memiliki:
- Flutter SDK
- Dart SDK (sudah termasuk dalam Flutter)
- Android Studio atau Visual Studio Code
- Android Emulator atau perangkat Android
- Android SDK

## Langkah Menjalankan Aplikasi
1. Clone atau unduh repositori proyek DrinkMate.
2. Buka folder proyek melalui Visual Studio Code atau terminal.
3. Jalankan perintah berikut untuk mengunduh dependensi:
   ```bash
   flutter pub get
   ```
4. Hubungkan perangkat Android atau jalankan Android Emulator.
5. Pastikan perangkat terdeteksi dengan perintah:

   ```bash
   flutter devices
   ```
6. Jalankan aplikasi menggunakan perintah:
   ```bash
   flutter run
   ```

Aplikasi DrinkMate akan dibangun dan dijalankan pada perangkat Android yang terhubung.
